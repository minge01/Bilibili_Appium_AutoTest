selenium>=4.26,<5.0


# ---- 图像识别（处理 Compose 界面控件无法抓取的场景）---------
# 【版本强耦合警告】下面三个包必须一起看，不可单独升级任何一个。
# 它们相互之间形成了很窄的兼容窗口，实测只有这一组能通过 pip 依赖解析：
#
#   1) Airtest 1.4.3（目前其最新版本）声明依赖：
#        numpy < 2.0                     （官方至今未适配 numpy 2.x）
#        opencv-contrib-python >=4.4.0.46, <=4.6.0.66
#
#   2) 因此 opencv 只能停在 4.6.0.66（Airtest 的上限）。
#      而 opencv 4.12+ 要求 numpy>=2，与 Airtest 的 numpy<2.0 直接冲突。
#
#   3) numpy 1.26.4 是 1.x 线的最新版，同时满足：
#        Airtest 的 numpy<2.0  与  opencv 4.6 的 numpy>=1.21 系约束。
#
#   结论：opencv-contrib-python==4.6.0.66 + numpy==1.26.4 + Airtest==1.4.3
#         是目前唯一能一次性通过 pip 解析的组合。
#
#   未来若 Airtest 发布支持 numpy 2.x 的版本，才可以把 opencv 与 numpy
#   一起升到 2.x 体系；单独升级任何一个都会导致 ResolutionImpossible。
#
# 【另一个关键约束】opencv-python 与 opencv-contrib-python 不可同时安装。
#   两者都向 site-packages/cv2 写入同名模块，后安装者会覆盖前者，
#   造成「pip 显示 A 版本、实际运行 B 版本」的错乱，并可能触发 ABI 崩溃。
#   Airtest 声明依赖 opencv-contrib-python，且其功能集完整覆盖 opencv-python，
#   因此本框架只保留 opencv-contrib-python 一个。
opencv-contrib-python==4.6.0.66

# 与 opencv-contrib-python 4.6.0.66 配套，同时满足 Airtest 的 numpy<2.0 约束。
numpy==1.26.4

# 提供 airtest.core.cv.Template，用于图像模板匹配点击。
Airtest==1.4.3
